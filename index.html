Project Purpose

The goal of this site is to maintain a reproducible engineering record of the Stallion VTOL V2 build. It documents not only successful results, but also manufacturing problems, reprints, slicer-specific requirements, configuration changes, test observations, and lessons learned.

This is an experimental RC VTOL aircraft project. Information presented here reflects this specific build and should be independently verified before being applied to another aircraft.
