Documentation Structure

Aircraft Family → Version → Build
1

Aircraft Family

Example: Stallion, Super Stingray VTOL, Talon 1400, or Stork.

2

Version

Example: Stallion V1 or Stallion V2. Versions remain isolated from each other.

3

Physical Build

Example: Build 01, Build 02, etc. Every aircraft gets its own manufacturing and flight history.

Per-Build Documentation

Standardized across all aircraft

Manufacturing & Assembly

3D printing, materials, slicer settings, part weights, reprints, hardware, wiring, assembly procedures, photos, and modifications.

Configuration & Flight Testing

ArduPilot firmware and parameters, ground testing, hover testing, flight-test records, BIN logs, engineering reports, and YouTube-linked test video.

aircraft/ ├── stallion/ │ ├── v1/ │ │ └── build-01/ │ │ ├── printing/ │ │ ├── components/ │ │ ├── assembly/ │ │ ├── ardupilot/ │ │ ├── flight-testing/ │ │ ├── engineering/ │ │ ├── media/ │ │ └── downloads/ │ └── v2/ │ └── build-01/ │ ├── printing/ │ ├── components/ │ ├── assembly/ │ ├── ardupilot/ │ ├── flight-testing/ │ ├── engineering/ │ ├── media/ │ └── downloads/ │ ├── super-stingray-vtol/ ├── talon-1400/ └── stork/

Media Strategy

Build photos and diagrams can be stored directly in the repository under each build's media/ directory. Flight and test video is better hosted on YouTube and embedded or linked from the appropriate flight-test page.

This keeps the GitHub repository lightweight while preserving a complete traceable record of each test event.
